Why we built it

Two forces pushed the AI off the cloud, onto a box.

Privacy

Your inbox stays yours

An email assistant means handing a vendor your entire inbox. For our customers that's a non-starter — content has to stay on hardware they own.

Economics

Hardware beats a meter

Routing every inference to the cloud is a recurring per-seat bill. A ~$500 one-time board beats a year of cloud calls. Margin only works on hardware.

Target fixed up front: agent, memory, and pipeline all run on one local box. No cloud account required to operate it.

  • Tokens go further — the 4B model only runs at classify/draft, not orchestration

[5:15–7:30] N8N AS AGENT LAYER — 135s. THE core "under the hood" slide. The insight: don't make a small model do orchestration. Decompose the agent into an n8n workflow where n8n owns ALL deterministic control flow — scheduling, dedup, branching on confidence, retries, idempotency locks — and the LLM is invoked ONLY at the nodes that need reasoning (classify, draft). Three payoffs: (1) token budget — a 4B model can't afford to "think" about control flow, so we don't ask it to; (2) determinism + observability — the routing is plain IF nodes you can review, and every transition is logged, not buried in model output; (3) it's visually editable — an operator can change the confidence threshold without touching code, and workflows version-control to git. This is how you make agents reliable on cheap hardware.

Under the hood · making a 4B model carry it

Spend the model only where it earns its tokens.

  • No-think classify — disable chain-of-thought; we want a label, not an essay
  • Confidence-gated routing — local for the routine majority, cloud only for the uncertain tail
  • Sender-scoped RAG — recall only this counterparty's history; no confabulation
  • Token-budgeted memory — injected recall is hard-capped so reasoning room survives

[9:15–11:00] OPTIMIZING THE MODEL — 105s. The techniques that make a 4B model production-viable. (1) No-think classify — we suppress chain-of-thought because we only need a category label; it's faster and cheaper. (2) Confidence routing (from the email agent) — most mail is routine and drafts locally; the long tail escalates to a 120B cloud model. (3) RAG is sender-scoped — only recall the current counterparty's history, which keeps context tight and avoids confabulation. (4) Memory injection is token-budgeted — at 4096 ctx every injected token steals reasoning room, so recall is capped. The Modelfile/pin detail: 4096 is the Goldilocks window; Hermes is pinned to 0.15.1 because 0.16's 64K floor is incompatible with a 4B model. Lesson: pin your digests.
